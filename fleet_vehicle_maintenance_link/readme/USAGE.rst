To use this module, you need to:

1. Go to the Maintenance application and open or create an equipment.
2. Set the related Vehicle field.
3. On the maintenance requests for that equipment, the equipment already
   links back to the vehicle.
4. Go to the Fleet application and open a vehicle to see the Maintenances
   smart button with the count of maintenance requests made on its linked
   equipments; click it to list them.
5. Go to Fleet > Fleet > Maintenances to list the maintenance requests whose
   equipment has a vehicle set.
