Usage
=====

To use this module, you need to:

1. Go to Fleet application.
2. Go to Fleet > Settings > Models > Category in the menu.
3. Create or edit a category inserting the category code.
4. Link this model category to a model.
5. Create a new vehicle with the model we set.
6. The code field in the vehicle will use the model category sequence by
   default.
