To use this module, you need to:
1. Go to Fleet application.
2. Go to Fleet > Configuration > Models and open a vehicle model.
3. Set the Preventive Interval (e.g. 10000) under the Preventive Maintenance group.
4. Open a vehicle linked to that model and confirm the Preventive Interval shows up.
5. Set a Fleet Manager on the vehicle so the activity can be assigned.
6. Register odometer readings for the vehicle.
7. When the distance since the last alert reaches the configured interval, a new
   alert record is created and a mail activity is scheduled for the manager.
8. Alerts are listed on the vehicle form in the Preventive Maintenance tab.
